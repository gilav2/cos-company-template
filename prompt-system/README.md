# Portable Prompt Runtime

This is a clean adaptation of the COS operating principles, not a verbatim export of its internal role prompts.

- `shared/WAKE_KERNEL.md`: world recovery and evidence.
- `shared/CONTINUOUS_DRIVE.md`: professional continuation loop.
- `roles/`: stable profession contracts.
- `launchers/`: first-entry and recurring role activation.
- `templates/BOUNDED_LOOP.md`: bounded mission loop.

**Composition:** launcher → role → kernel → continuous drive → verified environment/Jira → Git Gemara → native evidence.

The first agent creates a company-specific configuration and proposes additional roles; the template does not pretend a company has already been built.
