# Bounded Professional Loop

**Role:** canonical professional role, unchanged.
**Mission:** one bounded Jira objective or investigation.
**Completion:** evidence-based, externally checkable condition.

Repeat: recover mission's real state and relevant Git Gemara → formulate the next meaningful professional work prompt → execute with actual tools → verify result → update Jira and material Gemara → recover the mission again.

Do not invent completion, bypass approvals or select unrelated missions. Escalate real blockers with precise evidence and a next breadcrumb.
