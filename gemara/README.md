# Git-native Gemara

This Gemara preserves institutional reasoning in **versioned Git files**. It is intentionally distinct from the Confluence-backed Gemara vNext product.

- Read [PROTOCOL.md](PROTOCOL.md) before authoring.
- Create material records from [templates/REASONING_RECORD.md](templates/REASONING_RECORD.md).
- Store company-specific records under `gemara/records/`.
- Use pull requests and Git history for review, lineage and corrections.
- Link operational tasks to records, but do not confuse Jira status with reasoning authority.

The template contains **no imported COS/IAA decisions or company history**. It does not claim to implement a typed Registry, automated semantic projections or a Confluence Writer.
